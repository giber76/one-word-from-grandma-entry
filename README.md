One Word From Grandma: the single word Grandma would text about AI — **malarkey**.

Her warm, baffled dismissal of the whole AI fuss: everything the machines do, in her voice, is a load of malarkey. One word, funny on its own, instantly readable, and unmistakably Grandma.

## Run it

```sh
node main.ts
```

It writes `malarkey` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt`).
